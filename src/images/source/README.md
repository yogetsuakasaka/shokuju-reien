# src/images/source/ — 元画像の置き場所

ここに**元画像（切り出す前の写真）**を置きます。
ここに置いた画像は、サイトには直接使われません。
`npm run images` が、ここから各スロット用の画像を切り出して `src/images/` の下に書き出します。

---

## 置き方

1. **長辺4000px前後の JPEG** にしてから置く
   - いちばん解像度が必要なのは Hero のスマホ用（9:16の縦切り出し）です。
     3:2 の横写真から縦を切り出すため、元画像の長辺が4000px程度必要になります。
   - 6000px級の無圧縮原本は置かないでください。リポジトリが重くなり、
     **一度コミットすると履歴から消せません**。

2. **EXIF（位置情報）を外してから置く**
   - このリポジトリは公開されています。ここに置いた元画像は誰でもダウンロードできます。
   - ドローン写真には GPS 座標・機体情報・撮影日時が含まれています。
   - スマホから共有するときは「位置情報を含めない」を選んでください。
   - なお、**サイトに出力される画像からは EXIF が自動的に除去されます**（`sharp` の既定動作）。
     外していただきたいのは、この `source/` に置く元画像のほうです。

3. **ファイル名は連番＋内容がわかる英数字**
   ```
   01-monument-hoshi.jpg
   02-aerial-spring.jpg
   03-plots-rows.jpg
   04-circle-sakura.jpg
   ```
   - 半角英数字・小文字・ハイフンのみ。日本語・空白は使わない
   - どのスロットに使うかは `scripts/image-recipes.json` で決めるので、
     ファイル名をスロット名に合わせる必要はありません

4. **元画像は削除・上書きしない**
   - 切り出しをやり直したくなったときに元画像が必要です。ここに残したままにしてください。

---

## 置いたあと

```bash
npm run images:dry    # 何が作られるか確認（ファイルは書かれません）
npm run images        # 生成する
npm run build         # サイトをビルドして確認
```

切り出す位置は `scripts/image-recipes.json` で指定します。
書き方は CLAUDE.md「5. 写真を追加する」を参照してください。

---

## このフォルダは公開ビルドに含まれません

`src/images/source/` は、`Figure.astro` / `Hero.astro` の画像検索から除外してあります。
ここに何枚置いても、サイトの表示速度には影響しません。

# サイト分析レポート（週次・月次）の設定手順

Google スプレッドシートと Apps Script で、公式サイトの数値を毎週・毎月まとめ、
Claude（AI）が日本語の所見を書いてメールで届ける仕組みです。

- **週次**：毎週月曜 8時台に、3日前までの1週間を集計
  （Search Console は数値の確定に2〜3日かかるため）
- **月次**：毎月5日 8時台に、前月を集計（前月・前年同月と比較）
- **費用**：スプレッドシート・Apps Script・Google の API は無料。
  Claude API は**月1ドル前後**の見込み（`claude-opus-5-5`：入力 $4／出力 $20、いずれも100万トークンあたり）

このフォルダのファイル：

| ファイル | 役割 |
|---|---|
| `Code.gs` | 本体（Apps Script のエディタに貼り付ける） |
| `appsscript.json` | 権限とタイムゾーンの設定（同じく貼り付ける） |

> **このリポジトリは公開されています。** API キーはここに書かず、
> 下の手順4の「スクリプト プロパティ」にだけ保存してください。

---

## 1. スプレッドシートを作る

1. Search Console・GA4 と**同じ Google アカウント**で、新しいスプレッドシートを作ります
   （名前の例：「平成院 サイト分析」）
2. **他の人と編集権限で共有しないでください**（Apps Script の設定を見られるため）。
   閲覧だけなら共有して構いません

## 2. Apps Script にコードを入れる

1. スプレッドシートの「拡張機能」→「Apps Script」
2. 最初からある `コード.gs` の中身をすべて消し、`Code.gs` の内容を貼り付けて保存
3. 左の歯車「プロジェクトの設定」→「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック
4. エディタに出てきた `appsscript.json` の中身を、このフォルダの `appsscript.json` に置き換えて保存

## 3. Google Cloud プロジェクトを用意する（無料・課金の設定は不要）

Search Console のデータを Apps Script から読むために必要です。

1. https://console.cloud.google.com/ で「新しいプロジェクト」を作成（名前の例：`heiseiin-site-report`）
2. 「API とサービス」→「ライブラリ」で、次の2つを検索して「有効にする」
   - **Google Search Console API**
   - **Google Analytics Data API**
3. 「OAuth 同意画面」（Google Auth Platform）を設定
   - ユーザーの種類：**外部**
   - アプリ名：「平成院 サイト分析」、サポートメール：ご自身のアドレス
   - 対象（テストユーザー）に、ご自身のアドレスを追加
   - 設定が終わったら、公開ステータスを**「本番環境」**にします。
     テストのままだと、7日ごとに承認し直しが必要になる場合があります。
     Google の審査は不要です（承認画面に「確認されていません」と出るだけです）
4. プロジェクトの「ダッシュボード」で**プロジェクト番号**（数字）をコピー
5. Apps Script に戻り、「プロジェクトの設定」→「Google Cloud Platform（GCP）プロジェクト」
   →「プロジェクトを変更」に、コピーした番号を貼り付け

## 4. スクリプト プロパティを登録する

Apps Script の「プロジェクトの設定」→「スクリプト プロパティ」に追加します。

| プロパティ | 値 | 必須 |
|---|---|---|
| `GSC_SITE_URL` | `sc-domain:shokuju-reien.jp` | ○ |
| `REPORT_EMAIL` | レポートの送り先メールアドレス | ○ |
| `ANTHROPIC_API_KEY` | Claude API キー（下の説明） | 空なら数値だけのレポート |
| `GA4_PROPERTY_ID` | GA4 のプロパティID（数字。GA4「管理」→「プロパティの詳細」） | GA4 導入後 |
| `CLAUDE_MODEL` | 使うモデル。空なら `claude-opus-5-5` | 任意 |

**Claude API キーの作り方**：Claude Console（platform.claude.com）にログイン →「API Keys」で作成。
クレジットを少額だけ購入し、自動チャージをオフにしておくと、使いすぎを防げます。

## 5. 動かしてみる

エディタ上部の関数名を選んで「実行」を押します。

1. **`checkConnections`** … 初回は承認画面が出ます
   （「このアプリは Google で確認されていません」→「詳細」→「（安全ではないページ）に移動」→「許可」）。
   画面下の「実行ログ」に、Search Console・GA4・Claude API がそれぞれ「OK」と出れば成功です
2. **`setup`** … シート（KPI履歴・問い合わせ記録・レポート）と、週次・月次の自動実行を登録します
3. **`previewWeekly`** … メールは送らずに、シートと実行ログで結果を確かめます
4. **`runWeekly`** … 実際にメールが届くか確かめます

以後は自動で動きます。止めたいときは、Apps Script 左の「トリガー」（時計の形）から削除します。

## 6. 問い合わせ記録（事務局で記入）

シート「問い合わせ記録」に、1件1行で記入します。月次レポートで、サイトの数値と並べて見ます。

| 日付 | 種別 | きっかけ | メモ |
|---|---|---|---|
| 2026/11/20 | 電話 | ホームページ | |
| 2026/11/23 | 見学 | 紹介 | |

- **氏名・電話番号・住所は書かないでください。** AI に渡すのは件数だけですが、シート自体に残さないためです
- 「きっかけ」は、お電話の際に「何でお知りになりましたか」と伺えた場合に記入します

## 7. GA4 を導入したあとに

1. スクリプト プロパティ `GA4_PROPERTY_ID` に、GA4 のプロパティID（数字）を登録
2. GA4「管理」→「カスタム定義」→「カスタム ディメンションを作成」で、次の2つを登録（範囲：イベント）
   - ディメンション名「電話の回線」、イベント パラメータ `phone_line`
   - ディメンション名「電話リンクの位置」、イベント パラメータ `link_location`
   登録するまでは、電話タップは合計だけが集計されます
3. GA4「管理」→「イベント」で、`phone_click` を**キーイベント**にします

## 困ったとき

| 実行ログの表示 | 確認すること |
|---|---|
| Search Console … 403 | このアカウントが Search Console の `shokuju-reien.jp` を見られるか／手順3の API を有効にしたか |
| Search Console … 「API has not been used」 | 手順3の2・5（API の有効化と、プロジェクト番号の設定） |
| GA4 … 403 | このアカウントに GA4 プロパティの閲覧権限があるか |
| Claude API 401 | `ANTHROPIC_API_KEY` の値 |
| Claude API 429・529 | 混雑です。数値だけのレポートが届きます。次回は通常どおり動きます |
